Bank Customer Satisfaction Analysis

Project Overview

This project analyzes synthetic bank customer data to understand customer satisfaction, financial behavior, banking preferences and dissatisfaction patterns.

The project uses Python data analysis libraries to clean data, create new features, perform exploratory data analysis and visualize important findings.

Objectives

- Analyze overall customer satisfaction.
- Explore the relationship between customer financial behavior and satisfaction.
- Compare satisfaction across cities, account types, employment types, age groups and banking channels.
- Identify customers with satisfaction scores below 50.
- Suggest business recommendations based on the analysis.

Dataset

The dataset contains customer-related information, including:

- Customer ID
- Age
- City
- Monthly income
- Average account balance
- Monthly transactions
- Complaints
- Account type
- Employment type
- Preferred banking channel
- Satisfaction score
- Last transaction date

The dataset is synthetic and is used for educational and analytical purposes.
